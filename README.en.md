# Python Task Management System (CLI)

**English** | [Spanish version](./README.md)
---

This project was developed as an academic practice for the Data Structures and Algorithms I course. It consists of a command-line interface (CLI) application for task management, implementing linked lists, stacks, and queues to simulate real-world operations such as undoing actions, modifying tasks, or sending them to a print queue.

## 📌 Main Features

- add, modify, and delete tasks.
- Undo the last action (add, modify, or delete).
- Display registered tasks.
- Send tasks to a print queue and process them.
- Automatic ID assignment and console menu control.

## 🛠️ Technologies & Applied Concepts

- Python 3.
- Linked Lists.
- Stacks (undo feature).
- Queues (print queue).
- Modular Object-Oriented Programming (OOP).
- Control flow logic and input validation.

## ▶️ Usage

1. Run the program:
   ```bash
   python final.py
   ```

2. Follow the menu to:
   - Add tasks.
   - Modify fields.
   - Undo recent actions.
   - View the list or print tasks from the queue.
